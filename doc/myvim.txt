*myvim.txt*  myvim 插件能力一览                                    *myvim*

本手册列出 ~/.vim 配置中所有插件的用途、命令与快捷键。
新增插件时请同步维护本文档与 scripts/verify.vim。

==============================================================================
1. 插件管理                                                    *myvim-plug*

vim-plug            插件管理器
  :PlugInstall      安装 .vimrc 中声明的插件
  :PlugUpdate       更新全部插件
  :PlugClean        清理未声明的插件
  :PlugStatus       查看插件状态

==============================================================================
2. 补全与片段                                                *myvim-complete*

（语义补全/跳转由 vim-lsp 提供，详见 §8）
UltiSnips           代码片段引擎（需 python3，否则不声明）
  <leader><tab>     展开片段 / 跳到下一占位符
  <leader><s-tab>   跳到上一占位符
vim-snippets        片段库

==============================================================================
3. 文件与跳转                                              *myvim-navigation*

NERDTree            文件树（<C-n> 开关），显示隐藏文件
nerdtree-git-plugin 文件树中显示 git 状态图标
Tagbar              符号大纲（<F8> 开关）
fzf + fzf.vim       模糊搜索（需 fzf、ripgrep 二进制）
  <C-p>             :Files 模糊找文件
  <leader>rg        :Rg 全文搜索
vim-fswitch         <leader>swi 在 .cpp/.h 间切换
vim-gutentags       后台自动维护 ctags（缓存于 ~/.cache/tags）

==============================================================================
4. Git                                                          *myvim-git*

vim-fugitive        vim 内 Git
  :Git blame        逐行 blame
  :Git diff         diff
  :Git log          日志

==============================================================================
5. 编辑增强                                                 *myvim-editing*

auto-pairs          括号/引号自动配对（替代旧自研函数）
nerdcommenter       注释开关（<leader>c<space> 切换注释）
tabular             对齐（:Tab /字符）
<space>             折叠开关（cursor 在闭合 fold 上 zo 展开，否则 zc 折叠）
vim-surround 未装；自动配对由 auto-pairs 负责

==============================================================================
6. 语言支持                                               *myvim-languages*

vim-cpp-enhanced-highlight   C++ 增强高亮
pangloss/vim-javascript      JS 语法高亮/缩进（懒加载，编辑 .js 时才加载）
moll/vim-node                Node.js 文件类型支持（懒加载，编辑 .js 时加载）
vim-go                       Go 开发集成（编辑 .go 时加载 ftplugin）
  :GoBuild                   编译当前包
  :GoRun                     运行
  :GoTest                    测试
  :GoImport                   导入包
  :GoFmt                      格式化
  :GoDef                      跳转定义（gopls）
vim-markdown                 Markdown 高亮/折叠（懒加载）
vim-instant-markdown         浏览器实时预览（需 instant-markdown-d，懒加载）

==============================================================================
7. 界面与格式化                                                 *myvim-ui*

vim-airline         状态栏 + tabline
vim-indent-guides   缩进参考线（启动即启用，从第 2 级开始）
molokai             配色方案
vim-codefmt         保存时自动格式化
  :AutoFormatBuffer clang-format   手动触发格式化（c/cpp/proto/javascript）
  augroup autoformat_settings      保存 .c/.cpp/.proto/.js 时自动跑 clang-format
vim-maktaba + vim-glaive  codefmt 的依赖框架

==============================================================================
8. LSP (vim-lsp)                                              *myvim-lsp*

vim-lsp             LSP 客户端（替代 YCM，无需编译）
asyncomplete.vim    补全 popup 框架
asyncomplete-lsp.vim LSP↔asyncomplete 桥接（监听 User lsp_server_init 自动注册 source；打字时弹补全）

  clangd           C/C++ LSP（系统自带，无需 make coding）
  pyright          Python LSP（make coding 装，npm registry）
  gopls            Go LSP（make coding 装，proxy.golang.org）
  jdtls            Java LSP（make coding 装，brew bottle）

通用键绑定：
  gd               跳转定义 :LspDefinition
  gD               跳转声明 :LspDeclaration
  gi               跳转实现 :LspImplementation
  gr               查找引用 :LspReferences
  <leader>ca       code action :LspCodeAction
  <leader>rn       重命名 :LspRename
  K                悬停文档 :LspHover
  [d / ]d          上一/下一诊断
  <leader>ds       文档符号 :LspDocumentSymbol
  <leader>ws       工作区符号 :LspWorkspaceSymbol

LSP servers 与格式化器由 `make coding` 安装，详见 README.md。

==============================================================================
9. AI Coding (Claude Code)                                       *myvim-ai*

Claude Code CLI 集成（需 npm install -g @anthropic-ai/claude-code）
用 <leader>a* 前缀避开 NERDCommenter 的 <leader>c* 命名空间。

  <leader>ai       normal: 打开 Claude Code 终端（底部 20 行 split）
                   交互式对话,Claude 可读写项目文件、跑命令、改代码
  <leader>ab       visual: 选区 → Claude 改写（输出原地替换 buffer）
                   例:选中代码 → <leader>ab → 输入 prompt → Enter
                   失败可 u 撤销。适合"把这段改成 async/await"等
  <leader>aq       visual: 选区 → Claude 查询（输出到终端,不改 buffer）
                   适合"解释这段代码"等不需要改 buffer 的场景

任务分工建议：
  - 跳转/重命名/code action/单行小改 → 用 LSP（vim 内,即时）
  - 跨文件重构/写测试/读陌生代码/起草函数 → 用 Claude Code（<leader>ai）
  - 选区就地改写 → <leader>ab（带 prompt）
  - 选区查询解释 → <leader>aq
