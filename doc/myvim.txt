*myvim.txt*  myvim 插件能力一览                                    *myvim*

本手册列出 ~/.vim 配置中所有插件的用途、命令与快捷键。
新增插件时请同步维护本文档与 scripts/verify.vim。

==============================================================================
1. 日常编辑速查表                                        *myvim-cheatsheet*
   日常编辑速查表 — 不依赖插件,纯 vim 原生命令(高频,非专家级)

移动 -----------------------------------------------------------------------

  h j k l           左下上右(基础,新手用这个起步)
  w b e             下一词 / 上一词 / 到词末
  0 ^ $             行首 / 首字符 / 行末
  gg G              文件首 / 文件尾
  :N<CR>            跳到第 N 行(如 :42<CR>)
  { }               上一段 / 下一段(空行分隔,跨函数)
  %                 跳到配对括号 ( ) [ ] { }
  f<c> ; ,          行内下一处字符 c, ; 重复, , 反向
  * #               搜索当前词,下一/上一处
  Ctrl-o Ctrl-i     jumplist 上一/下一处(跳转后回去就靠这个)
  Ctrl-d Ctrl-u     半页下/上滚
  H M L             屏幕顶/中/底

插入 -----------------------------------------------------------------------

  i a o             光标前/后插入 / 下一行新行插入
  I A O             行首/末插入 / 上一行新行插入
  Esc               回 normal 模式(也可用 Ctrl-[)

删除 / 改写 --------------------------------------------------------------

  x                 删字符
  dd                删整行(进默认寄存器,可 p 粘回)
  dw db de          删词 / 上一词 / 到词末
  D                 删到行末
  cc cw             改整行 / 改词(进 insert 模式)
  r<c>              替换当前字符为 c
  ~                 切换当前字符大小写
  u  Ctrl-r         撤销 / 重做

复制 / 粘贴 --------------------------------------------------------------

  yy                复制整行(也可 5yy 复制 5 行)
  yw y$             复制词 / 到行末
  p P               粘在光标后 / 前
  "+y  "+p          系统剪贴板复制/粘贴(粘到其他 app)
  "+yy              复制当前行到系统剪贴板

Visual 选区 --------------------------------------------------------------

  v                 字符级选(细粒度)
  V                 行级选(整行, V5jy 选 6 行复制)
  Ctrl-v            块选(矩形,多行同步编辑用)
  o                 切换选区活动端(改起点/终点,选多了可退)
  gv                重选上次选区

块选常用操作(替代多光标)------------------------------------------------
  Ctrl-v 选 → I... Esc    多行行首插入相同文本(如批量加 //)
  Ctrl-v 选 → A... Esc    多行行末追加(如批量加 ;)
  Ctrl-v 选 → c... Esc    矩形替换
  Ctrl-v 选 → x           矩形删

搜索 / 替换 --------------------------------------------------------------

  /pattern<CR>      搜索 pattern
  n N               下一/上一匹配
  :%s/old/new/gc    全文件替换(g=全部 c=逐个确认)
  V 选 → :s/old/new/g    选区内替换(visual 自动填 :'<,'>)

缩进 -----------------------------------------------------------------------

  >> <<             当前行右/左移
  ==                当前行自动缩进(按文件类型)
  V 选 → =          选区自动缩进(格式化整段)

重复 -----------------------------------------------------------------------

  .                 重复上次修改(高频神器,改完跳下一处按 . 即可)
  u                 撤销

窗口 / Buffer ------------------------------------------------------------

  Ctrl-w h/j/k/l    切换左/下/上/右窗口
  Ctrl-w v  Ctrl-w s    垂直/水平分屏
  Ctrl-w c          关闭当前窗口
  :bn :bp          下一/上一 buffer(切换打开的文件)
  :ls               列出所有 buffer

文件 -----------------------------------------------------------------------

  :w  :q  :wq  :q!  保存 / 退出 / 保存退出 / 强制退出
  :e <file>         打开文件
  :saveas <file>    另存为

宏(多行重复)------------------------------------------------------------

  qa ... q          录制宏到寄存器 a
  @a                重放宏 a 一次
  5@a               重放 5 次
  @@                重放上次宏

学习路径 -----------------------------------------------------------------

  vimtutor          终端命令,30 分钟交互式教程(新手首日必做)
  :help usr_02      到 :help usr_45 用户手册章节
  :help quickref    vim 官方速查卡

9. LSP (vim-lsp)                                              *myvim-lsp*

vim-lsp             LSP 客户端（替代 YCM，无需编译）
asyncomplete.vim    补全 popup 框架
asyncomplete-lsp.vim LSP↔asyncomplete 桥接（监听 User lsp_server_init 自动注册 source；打字时弹补全）

  clangd           C/C++ LSP（系统自带，无需 make coding）
  pyright          Python LSP（make coding 装，npm registry）
  gopls            Go LSP（make coding 装，proxy.golang.org）
  jdtls            Java LSP（make coding 装，brew bottle）

通用键绑定：
  gd               跳转定义 :LspDefinition
  gD               跳转声明 :LspDeclaration
  gi               跳转实现 :LspImplementation
  gr               查找引用 :LspReferences
  <leader>ca       code action :LspCodeAction
  <leader>rn       重命名 :LspRename
  K                悬停文档 :LspHover
  [d / ]d          上一/下一诊断
  <leader>ds       文档符号 :LspDocumentSymbol
  <leader>ws       工作区符号 :LspWorkspaceSymbol

LSP servers 与格式化器由 `make coding` 安装，详见 README.md。

10. AI Coding (Claude Code)                                       *myvim-ai*

Claude Code CLI 集成（需 npm install -g @anthropic-ai/claude-code）
用 <leader>a* 前缀避开 NERDCommenter 的 <leader>c* 命名空间。

  <leader>ai       normal: 打开 Claude Code 终端（底部 20 行 split）
                   交互式对话,Claude 可读写项目文件、跑命令、改代码
  <leader>ab       visual: 选区 → Claude 改写（输出原地替换 buffer）
                   例:选中代码 → <leader>ab → 输入 prompt → Enter
                   失败可 u 撤销。适合"把这段改成 async/await"等
  <leader>aq       visual: 选区 → Claude 查询（输出到终端,不改 buffer）
                   适合"解释这段代码"等不需要改 buffer 的场景

任务分工建议：
  - 跳转/重命名/code action/单行小改 → 用 LSP（vim 内,即时）
  - 跨文件重构/写测试/读陌生代码/起草函数 → 用 Claude Code（<leader>ai）
  - 选区就地改写 → <leader>ab（带 prompt）
  - 选区查询解释 → <leader>aq
